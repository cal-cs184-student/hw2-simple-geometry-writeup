Section I: Bezier Curves and Surfaces

Part 1: Bezier Curves with 1D de Casteljau Subdivision

Bezier curves are smooth parametric polynomial curves, which are defined based on a series of control points. These control points determine the Bezier curve such that it always passes through the first and last control points, and the intermediate points between act as "magnets," pulling on the curve and helping shape it despite not actually lying on the curve. Bezier curves play a major role in computer graphics because they enable us to model approximations of more complex shapes found in the real world.

The de Casteljau algorithm is a simple way to, given the control points for a Bezier curve, find points that lie on the Bezier curve itself at given parameter values. For n control points and a parameter value of t, we can calculate n-1 intermediate control points at t, where an intermediate point is calculated as: \(p_{i} = (1 - t)*p_{i} + t*p_{i+1}\), for \(1 \leq i \leq n-1 \). Once a subdivision of intermediate points is computed, we can then recursively continue computing these sets of intermediate points until a single point is interpolated, and this point will lie on the Bezier curve. A full Bezier curve can thus be evaluated from these control points by completing all recursive subdivisions at all values of the parameter t. In my code, I implemented this recursively so that each call to the evaluation function completes one level of subdivision by interpolating between the adjacent pairs of given points and returning these interpolations; if there is only one given point, the recursion ends there.
