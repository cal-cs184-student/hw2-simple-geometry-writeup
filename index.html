Section I: Bezier Curves and Surfaces

Part 1: Bezier Curves with 1D de Casteljau Subdivision

Bezier curves are smooth parametric polynomial curves that are defined by a series of control points. These control points determine the Bezier curve such that it always passes through the first and last control points, and the intermediate points between act as "magnets," pulling on the curve and helping shape it despite not actually lying on the curve. Bezier curves play a major role in computer graphics because they enable us to model approximations of more complex shapes found in the real world.

The de Casteljau algorithm is a simple way to, given the control points for a Bezier curve, find points that lie on the Bezier curve itself at specific parameter values. For n control points and a parameter value of t, we can calculate n-1 intermediate control points at t, where an intermediate point is calculated as: \(p_{i} = (1 - t)*p_{i} + t*p_{i+1}\), for \(1 \leq i \leq n-1 \). Once a subdivision of intermediate points is computed, we can then recursively continue computing these sets of intermediate points until a single point is interpolated, and this point will lie on the Bezier curve. A full Bezier curve can thus be evaluated from these control points by completing all recursive subdivisions at all values of the parameter t. In my code, I implemented this process so that each call to the evaluation function completes one level of subdivision by interpolating between the adjacent pairs of given points and returning these interpolations; if there is only one given point, no interpolation needs to occur and the process ends there.

Part 2: Bezier Surfaces with Separable 1D de Casteljau

The concept of Bezier curves can be generalized to 3D, where a Bezier surface is defined by a grid of control points in 3D space and parameters u and v. We can think of each row of points as a set of 2D control points, and then use the de Casteljau algorithm and the parameter u as above to recursively subdivide until we reach a final point for every row in the grid. This resulting set of intermediate points then acts as control points for a Bezier curve parametrized by v in the column-wise direction, so we can once again use the de Casteljau algorithm with the parameter v to obtain the final point, which lies on the Bezier surface at the parameters u and v. Therefore we are separating the evaluation of the Bezier surface into evaluation of Bezier curves along one orientation, then evaluating the resulting curve along the other orientation. Additionally, evaluating the Bezier surface first by columns and then by rows produces the same result as first by rows and then by columns.

Implementation of this process was simple: for each row vector in the grid of control points, I used the evaluate1D function (which returns the final result point on the Bezier curve from a given set of control points) with parameter u, appending the results into another vector. I then used the evaluate1D function on this result vector with parameter v to obtain the point which lies on the Bezier surface.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-Weighted Vertex Normals

Triangle meshes are an alternative to Bezier curves when it comes to representing surfaces. However, while triangle meshes are easier to directly render than Bezier curves, they do require more memory and also don't represent smooth surfaces very well. This latter part becomes especially evident when attempting to shade surfaces, where flat shading (shading every triangle according to its face's normal vector) results in a very blocky appearance. Phong shading creates a drastically improved appearance, providing smooth shading and realistic specular lighting despite not changing the triangle mesh. This approach is accomplished by interpolating vertex normals across the triangle, where the normal of a vertex is calculated as the normalization of the sum of all area-weighted normals of the faces connected to the vertex.

I implemented this in my code by iterating through all of the half-edges that emerge from the given vertex. For each half-edge, I calculate the area of the associated triangle face as \( \frac{1}{2} * ||\vec{u} \times \vec{v}|| \), where u and v are the vectors that extend from the current vertex to the two other vertices of the triangle. I multiply this face area by the face's normal, then add it to the sum of the face normals over all of the faces connected to the given vertex. Finally, I normalize the sum of these face normals, which produces the area-weighted vertex normal that can be used for Phong shading. One of these simple operations is an edge flip, where an edge between two triangles is instead attached at the other two vertices of the parallelogram formed by the two triangles.
